# File Manager Pro — מנהל קבצים פרו לאנדרואיד (גירסה 0.3.7)

**File Manager Pro** הוא מנהל קבצים נייטיב מהיר, מאובטח וקל-משקל לאנדרואיד (Java 17), המעוצב בעברית מלאה (RTL) עם תמיכה בכל גדלי המסכים, במערכות מדיה פנימיות מתקדמות, בעורך קוד מובנה ובמנוע ארכיונים ללא תלויות כבדות.

## תכונות עיקריות (גירסה 0.3.7)
- **תיקון יסודי של נגן והמרת MTS/M2TS:** מניעת סימון פריימים שגויים ב-SeekableTsExtractor, שמירת סדר תצוגת B-frames + הזרקת תיבת `ctts` ב-`TsToMp4Remuxer`, מאגרי טעינה מוגדלים וביטול עומס מפענח מקבילי.
- **אינדקס SQLite מהיר, מיון מספרים-תחילה, שיתוף מערכת ו-OTG:** חיפוש מיידי ב-SQLite, מיון טבעי המקדים מספרים (`2` לפני `10`) ואחר כך עברית, כניסה אוטומטית לראש הרשימה, שיוך קבצים במניפסט ("פתח באמצעות"), והוצאה בטוחה של SD/USB.
- **ממשק זכוכית שקופה, וילונות צד ופס גלילה 1.5 שניות:** וילונות צד מונפשים, פס הרצה מהיר בצד ימין המופיע בגלילה ונעלם אחרי 1.5 שניות, החזרת המיני-נגן לתיקיית השמע וחזרה מדורגת, ותמונות ממוזערות לרשת קטגוריות מדיה.
- **עורך תמונות ונגני מדיה עם PiP וסיבוב תור:** עורך תמונות במסך מלא, PiP בווידאו, נקודות 5% בפסי ההתקדמות, מצב מחוות משופר, ותור שמע בגרירה.
- **עורך קוד מתקדם ותצוגת Markdown/SVG:** סרגל כלים מאוחד עם חיפוש והחלפה פנימיים עם מעבר בין תוצאות, מידע חי על שורות/מילים/תחביר/קידוד, תצוגת Markdown כברירת מחדל עם מעבר מהיר לקוד, והדגשת תחביר מלאה.
- **מנהל ארכיונים מלא:** פתיחה, צפייה פנימית, עריכה חיה, הוספה וחילוץ של קבצי `ZIP`, `TAR`, `TAR.GZ`, `TGZ` ו-`GZ`, כולל תמיכה בהצפנה ובקשת סיסמה אוטומטית בעת הצורך והגנת `Zip-Slip`.
- **עדכונים מאובטחים דרך רשתות מסוננות (נטפרי):** תמיכה אוטומטית בתעודות אבטחה שהמשתמש התקין במכשיר, עם אימות דומיין קשיח ומאובטח לדומייני GitHub בלבד.
- **החלקה לבחירה מרובה והתראות התקדמות:** לחיצה ארוכה על קובץ לפתיחת תפריט פעולות, החלקה לצד לכניסה לבחירה מרובה, ודיאלוג והתראת התקדמות בזמן אמת הניתנים להסתרה.
- **הפחתת משקל וידאו, חותכי מדיה ובחירה מתוך הקטגוריות:** המרת רזולוציה והפחתת משקל לווידאו, ובחירת קובצי שמע ווידאו לחיתוך מתוך קטגוריות האפליקציה.
- **מדיה ונגנים מובנים ברמת Pro:**
  - **תמונות ו-GIF:** תמיכה מלאה בהנפשת `GIF`, פירוק ל-PNG, הפיכה ל-MP4, יצירת GIF מתמונות או מוידאו, זום עמוק, קביעת טפט בחיתוך, ומחיקת מידע מטה-נתונים.
  - **וידאו ושמע:** תמיכה בנגן פנימי או מערכת, מצב מחוות אוטומטי (הקשה כפולה, לחיצה ארוכה להרצה 2x), תור ניגון ברקע, טיימר שינה, אקולייזר, וחותך אודיו ווידאו.
- **אפליקציות, OTG ומנתח קוד APK:**
  - התקנה אוניברסלית של `APK`, `APKX`, `APK+`, `APKS`, `APKM`, `XAPK` עם זיהוי גירסה חדשה במכשיר.
  - ניהול אפליקציות מותקנות (גיבוי, שיתוף, הסרה) וצפייה במבנה ה-APK (`AndroidManifest.xml` ו-`DEX`).
  - זיהוי כונני `USB OTG` מחוברים בזמן אמת ויומן שגיאות יומי נקי מפרטים מזהים.

## מבנה הפרויקט ובנייה
- פותח ב-Java 17 על Android SDK 34 (`minSdk 26`).
- קבצי המקור ב-`app/src/main/java/com/aishhatorah/filemanagerpro/`.
- בדיקות יחידה (JUnit 4) ב-`app/src/test/java/com/aishhatorah/filemanagerpro/`.
- הפעלת בדיקות ובנייה:
  ```bash
  gradle testReleaseUnitTest --no-daemon
  gradle assembleRelease --no-daemon
  ```
