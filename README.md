# File Manager Pro — מנהל קבצים פרו לאנדרואיד (גירסה 0.3.6)

**File Manager Pro** הוא מנהל קבצים נייטיב מהיר, מאובטח וקל-משקל לאנדרואיד (Java 17), המעוצב בעברית מלאה (RTL) עם תמיכה בכל גדלי המסכים, במערכות מדיה פנימיות מתקדמות, בעורך קוד מובנה ובמנוע ארכיונים ללא תלויות כבדות.

## תכונות עיקריות (גירסה 0.3.6)
- **מנוע חיפוש מהיר מבוסס אינדקס SQLite + זרימת וידאו MTS חלקה ו-PiP:** איתור מיידי של כל הקבצים והתיקיות בכל האחסון, נגן וידאו יציב ללא קריסות ותקיעות ב-MTS, תמונה בתוך תמונה (PiP) מתפריט ה-+, וזיהוי פתיחה באמצעות ו-USB OTG כברירת מחדל.
- **ממשק זכוכית שקופה ורקע מותאם אישית:** בחירת טפט רקע עם מחוון עוצמת טשטוש ובהירות, כותרות שקופות מעוגלות, כרטיסיות נושא מאוזנות בגודל שווה (12 ערכות נושא ו-16 צבעי דגש), ואיפוס מהיר לגודל הטקסט.
- **נגני מדיה, פסי גלים ומסכי צפייה משודרגים:** פסי התקדמות עבים ומעוגלים עם סמן עומד מיושר, גלי תנועה לאחור בנגני הווידאו והשמע, מציג תמונות על כל המסך עם אייקונים נקיים מעל רקע שקוף למחצה, ומציג PDF מוגדל עם חיצי דפדוף.
- **עורך והפחתת משקל וידאו + בחירת מדיה מתוך הקטגוריות:** המרת רזולוציה והפחתת משקל לווידאו ישירות מהעורך ומחותך הווידאו, ובחירת קובצי שמע ווידאו לחיתוך מתוך קטגוריות האפליקציה.
- **מנהל ארכיונים מלא:** פתיחה, צפייה פנימית, עריכה חיה, הוספה ומחיקה בתוך קבצי `ZIP`, `TAR`, `TAR.GZ`, `TGZ` ו-`GZ`, כולל תמיכה בהצפנה ובקשת סיסמה אוטומטית בעת הצורך והגנת `Zip-Slip`.
- **עדכונים מאובטחים דרך רשתות מסוננות (נטפרי):** תמיכה אוטומטית בתעודות אבטחה שהמשתמש התקין במכשיר, עם אימות דומיין קשיח ומאובטח לדומייני GitHub בלבד.
- **תפריט המבורגר ובחירה מרובה:** מיון לפי שם/יצירה/שינוי/גודל/סוג, לחיצה ארוכה לבחירה מרובה עם סרגל פעולות אחיד, שינוי שם אצווה, העתקה/העברה/שיתוף מרובה, סרגל נתיב לחיץ (Breadcrumbs), והתראות התקדמות בזמן אמת.
- **עורך קוד וטקסט מתקדם:** מספור שורות, ספירת מילים ושורות, Undo/Redo, חיפוש והחלפה, עטיפת שורות, צביעת תחביר ל-20+ שפות תכנות, תצוגת `Markdown` ו-`SVG`, וגיבוי אוטומטי `.bak` עם שחזור מהיר.
- **מדיה ונגנים מובנים ברמת Pro:**
  - **תמונות ו-GIF:** תמיכה מלאה בהנפשת `GIF`, פירוק ל-PNG, הפיכה ל-MP4, יצירת GIF מתמונות או מוידאו, זום עמוק, קביעת טפט בחיתוך, ומחיקת מידע מטה-נתונים.
  - **וידאו ושמע:** תמיכה בנגן פנימי או מערכת, מצב מחוות אוטומטי (הקשה כפולה, לחיצה ארוכה להרצה 2x), תור ניגון ברקע, טיימר שינה, אקולייזר, וחותך אודיו ווידאו.
- **אפליקציות, OTG ומנתח קוד APK:**
  - התקנה אוניברסלית של `APK`, `APKX`, `APK+`, `APKS`, `APKM`, `XAPK` עם זיהוי גירסה חדשה במכשיר.
  - ניהול אפליקציות מותקנות (גיבוי, שיתוף, הסרה) וצפייה במבנה ה-APK (`AndroidManifest.xml` ו-`DEX`).
  - זיהוי כונני `USB OTG` מחוברים בזמן אמת ויומן שגיאות יומי נקי מפרטים מזהים.

## מבנה הפרויקט ובנייה
- פותח ב-Java 17 על Android SDK 34 (`minSdk 26`).
- קבצי המקור ב-`app/src/main/java/com/aishhatorah/filemanagerpro/`.
- בדיקות יחידה (JUnit 4) ב-`app/src/test/java/com/aishhatorah/filemanagerpro/`.
- הפעלת בדיקות ובנייה:
  ```bash
  gradle testReleaseUnitTest --no-daemon
  gradle assembleRelease --no-daemon
  ```
