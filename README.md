## מה חדש בגירסה 0.2.7 רשמית

1. **תצוגת וידאו ותמונות נקייה בהקשה ומסך מלא בסיבוב:**
   - בהקשה על וידאו או תמונה מוצגים הוידאו והתמונות בלבד ללא שאר האופציות, ובהקשה שנייה האופציות חוזרות.
   - בסיבוב מסך הוידאו מוצג בתצוגה מלאה על פני כל המסך, ביחס תצוגה מדויק ללא מעיכה ובאיכות צלולה וברורה מאוד.
2. **דפדוף בין תמונות והגדלה עמוקה בחדות מלאה:**
   - בכל תמונה שנפתחת ניתן להעביר קדימה או אחורה לתמונות הבאות בתיקייה (בלחצנים או בהחלקה), ולהגדיל את התמונות הרבה (עד פי 25) בצורה צלולה וחדה מאוד.
3. **תיקון תצוגת רשת ופס הרצה בצד ימין:**
   - תצוגת הרשת בתיקיות ובקטגוריות מותאמת בדיוק לסגנון המסך הראשי (3 עמודות ממורכזות).
   - נוסף פס הרצה בצד ימין לגלילה מהירה מלמעלה למטה בכל התיקיות ובכל הקטגוריות של כל הקבצים.
4. **התקנת קובצי `APKX` ו-`APK+` וזיהוי גירסה חדשה מותקנת:**
   - תמיכה בהתקנת כל סוגי האפליקציות ללא יוצא מן הכלל (`.apk`, `.apkx`, `.apk+`, `.apks`, `.apkm`, `.xapk`).
   - במידה וקיימת במכשיר גירסה חדשה יותר לאפליקציה שבאים להתקין, מוצגת התראה מפורטת הכוללת את פרטי האפליקציה המותקנת ופרטי הקובץ שבאים להתקין.
5. **התאמה מלאה לכל גודלי המסכים:**
   - התאמה דינמית של כל המסכים, האייקונים והדיאלוגים לכל גודלי המסכים באשר הם.

## מה חדש בגירסה 0.2.6 רשמית

1. **תצוגת תיקיות ברשת לתמונות וסרטונים:**
   - בכניסה לקטגוריות **תמונות** או **סירטונים** הקבצים מוצגים בתיקיות שלהם בתצוגת רשת, ובתוך התיקיות התצוגה היא תצוגת רשת עם אפשרות למעבר לתצוגת רשימה.
   - בהגדרות האפליקציה ניתן לשנות בין תצוגת רשת לתצוגת רשימה עבור כל הקטגוריות באפליקציה (כולל תמונות וסרטונים).
2. **עריכת קובצי טקסט ישירה בנגיעה באותיות:**
   - בכניסה לקובץ טקסט, נגיעה באותיות פותחת את המקלדת למחיקה או הוספת מילים ושמירה ישירה בקובץ.
3. **ניקיון כותרות בקטגוריות:**
   - הוסר הכיתוב המיותר `קטגוריה: שמע` וכדומה בכניסה לקטגוריות השונות.
