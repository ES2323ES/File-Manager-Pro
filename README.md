## מה חדש בגירסה 0.2.3

1. **פתיחה פנימית מלאה של כלל הקבצים בתוך האפליקציה (ללא "פתח באמצעות"):**
   נגן שמע מובנה, נגן סרטונים מובנה, מציג תמונות חד, קורא PDF מובנה (`PdfRenderer`), קורא מסמכי Office (`.docx`, `.xlsx`, `.pptx`) וקורא טקסט, וכן חילוץ ארכיוני `.zip` ישירות מתוך האפליקציה.
2. **דחיסה לקובץ ZIP ויצירה מהירה מלחצן `+`:**
   בלחיצה ארוכה או בלחיצה על שלוש הנקודות (מצד ימין) נוספה אפשרות לדחיסת כל קובץ או תיקייה לארכיון `.zip`. לחצן ה-`+` למעלה משמאל בתיקיות מאפשר יצירת **תיקייה חדשה** או **קובץ חדש**.
3. **נפחים בזמן אמת במסך הבית ומיון תיקיות בעברית תחילה:**
   הצגת הנפח המדויק תחת קטגוריות ההורדות, תמונות, שמע, סירטונים, מסמכים, אפליקציות, קבצים חדשים וסל המיחזור, והצגת תיקיות בעברית לפני תיקיות באנגלית.
4. **תפריטים מותאמים לגוון האפליקציה ותצוגת רשת / רשימה:**
   כל התפריטים, הדיאלוגים וכפתורי **סגור** / **הבנתי** מותאמים באופן מלא למצבי **בהיר**, **כהה** ו-**ניאון**, כולל בחירה נוחה בין תצוגת רשימה לתצוגת רשת בהגדרות ואישור כפול בריקון סל המיחזור ובאיפוס הגדרות.
5. **חותך אודיו מקצועי וחותך וידאו מקצועי עם שיתוף ישיר:**
   חיתוך מהיר ללא פגיעה באיכות המקור ואפשרות לשיתוף מיידי של הקובץ שנחתך בלחיצה אחת.
6. **מנגנון עדכון אוטומטי חכם ויומן שינויים מובנה:**
   הודעת עדכון קופצת בכניסה לאפליקציה **אך ורק** כאשר קיימת גירסה חדשה יותר ב-GitHub, מציגה את מספר הגירסה החדשה ופירוט השינויים, מתקינה אוטומטית ומציגה בסיום **File Manager Pro עודכן בהצלחה**.
