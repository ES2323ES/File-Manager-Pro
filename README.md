# File Manager Pro — מנהל קבצים פרו לאנדרואיד (גירסה 0.2.9 רשמית)

**File Manager Pro** הוא מנהל קבצים נייטיב מהיר, מאובטח וקל-משקל לאנדרואיד (Java 17), המעוצב בעברית מלאה (RTL) עם תמיכה בכל גדלי המסכים, במערכות מדיה פנימיות מתקדמות, בעורך קוד מובנה ובמנוע ארכיונים ללא תלויות כבדות.

## תכונות עיקריות (גירסה 0.2.9)
- **נגן וידאו אמין בכל הפורמטים ומטמון קטגוריות מהיר (MediaStore):** שליטה מלאה בהפעלה, השהייה וגרירת ציר זמן בכל פורמטי הווידאו (עם פתיחה חלופית בנגן מערכת בעת הצורך) וטעינה מיידית בכל הקטגוריות (תמונות, שמע, סירטונים, מסמכים, אפליקציות, חדשים).
- **עדכונים מאובטחים דרך רשתות מסוננות (נטפרי):** תמיכה אוטומטית בתעודות אבטחה שהמשתמש התקין במכשיר, עם אימות דומיין קשיח ומאובטח לדומיינים הרשמיים של GitHub בלבד.
- **מנהל ארכיונים מלא:** פתיחה, צפייה פנימית, עריכה חיה, הוספה ומחיקה בתוך קבצי `ZIP`, `TAR`, `TAR.GZ`, `TGZ` ו-`GZ`, כולל תמיכה מלאה בהצפנה ופענוח בסיסמה (`ZipCrypto`) והגנת `Zip-Slip`.
- **ממשק מינימליסטי וערכות נושא מתקדמות:** ערכות נושא מותאמות (`בהיר`, `כהה`, `שחור עמוק AMOLED`, `אוקיינוס`, `יער`, `ניאון`, ו`לפי מערכת Material You`), בחירת צבע דגש מרכזי ומחוון שינוי גודל תצוגה וטקסט.
- **תפריט המבורגר ובחירה מרובה:** מיון לפי שם/יצירה/שינוי/גודל/סוג, לחיצה ארוכה לבחירה מרובה, שינוי שם אצווה, העתקה/העברה/שיתוף מרובה, סרגל נתיב לחיץ (Breadcrumbs), והתראות התקדמות בזמן אמת.
- **עורך קוד וטקסט מתקדם:** מספור שורות, ספירת מילים ושורות, Undo/Redo, חיפוש והחלפה, עטיפת שורות, צביעת תחביר ל-20+ שפות תכנות, תצוגת `Markdown` ו-`SVG`, וגיבוי אוטומטי `.bak` עם שחזור מהיר.
- **מדיה ונגנים מובנים ברמת Pro:**
  - **תמונות ו-GIF:** תמיכה מלאה בהנפשת `GIF`, פירוק ל-PNG, הפיכה ל-MP4, יצירת GIF מתמונות או מוידאו, זום עמוק, קביעת טפט בחיתוך, ומחיקת מידע מטה-נתונים.
  - **וידאו ושמע:** תמיכה בנגן פנימי או מערכת, מצב מחוות אוטומטי (הקשה כפולה, לחיצה ארוכה להרצה ×2), תור ניגון ברקע, טיימר שינה, אקולייזר, וחותך אודיו ווידאו.
- **אפליקציות, OTG ומנתח קוד APK:**
  - התקנה אוניברסלית של `APK`, `APKX`, `APK+`, `APKS`, `APKM`, `XAPK` עם זיהוי גירסה חדשה במכשיר.
  - ניהול אפליקציות מותקנות (גיבוי, שיתוף, הסרה) וצפייה במבנה ה-APK (`AndroidManifest.xml` ו-`DEX`).
  - זיהוי כונני `USB OTG` מחוברים בזמן אמת ויומן שגיאות יומי נקי מפרטים מזהים.

## מבנה הפרויקט ובנייה
- פותח ב-Java 17 על Android SDK 34 (`minSdk 26`).
- קבצי המקור ב-`app/src/main/java/com/aishhatorah/filemanagerpro/`.
- בדיקות יחידה (JUnit 4) ב-`app/src/test/java/com/aishhatorah/filemanagerpro/`.
- הפעלת בדיקות ובנייה:
  ```bash
  gradle testReleaseUnitTest --no-daemon
  gradle assembleRelease --no-daemon
  ```
