# File Manager Pro — מנהל קבצים מתקדם לאנדרואיד

**File Manager Pro** הוא מנהל קבצים נייטיב מהיר, מאובטח וקל-משקל לאנדרואיד (Java 17), המעוצב בעברית מלאה (RTL) עם ממשק זכוכית שקופה (Frosted Glass), נגנים ומציגי מדיה ומסמכים פנימיים, עורך קוד מובנה, מנוע ארכיונים מלא וכלי מערכת ואפליקציות ללא תלויות מנופחות.

---

## סקירת יכולות האפליקציה

### מסך הבית, אחסון וניווט
- **מסך בית מודולרי בהתאמה אישית:** גישה מיידית לאחסון הפנימי, כרטיס SD, כונני USB OTG, הורדות, אפליקציות, קטגוריות מדיה ומסמכים, סל מחזור ומנתח אחסון.
- **סידור בגרירה ידנית:** ארגון חופשי של האריחים במסך הבית והפרדה לקטעים בגרירה (Drag & Drop), כולל אפשרות להסתרת שמות הקטגוריות והצגת קיצור לכניסה מהירה לתיקייה האחרונה.
- **זיהוי USB OTG והוצאה בטוחה:** זיהוי חי של כונני USB ו-SD עם תפריט צף בהחזקה ארוכה לפתיחה או להוצאה בטוחה מבלי להזיז את שאר הסמלים.
- **מנתח אחסון וסל מחזור:** התרעת מקום נמוך מעל 96%, ניתוח תיקיות וקבצים כבדים, פח אשפה מובנה לשחזור ומחיקה סופית וניקוי מטמון מרוכז.

### דפדפן קבצים מהיר וחכם
- **אינדקס SQLite וביצועים משופרים:** חיפוש מיידי במאגר מקומי, האצת סריקה ומיון בתיקיות גדולות ובכרטיסי זיכרון, ומטמון תוצאות לקטגוריות.
- **מיון טבעי לכל תיקייה:** מיון שמקדים מספרים (`2` לפני `10`) ועברית לפני אנגלית, עם שמירת צורת המיון העצמאית לכל תיקייה בנפרד (ומניעת דריסה גלובלית של ברירת המחדל).
- **תצוגת רשימה או רשת:** גודל קבצים ומונה פריטים אסינכרוני בתיקיות, תצוגה מוקטנת אופציונלית לתיקיות, פס גלילה מהיר ודפדוף נוח.
- **בחירה מרובה ופעולות אצווה:** כניסה לבחירה מרובה בלחיצה ארוכה או בהחלקה לצד, וילון פעולות תחתון הניתן להרחבה בהחלקה למעלה/למטה, שינוי שם אצוותי, גזירה, העתקה, דחיסה והתראות התקדמות בזמן אמת הניתנות להסתרה.

### מציגי מסמכים, PDF, תמונות ועורך קוד
- **מציג PDF צף ומשודרג:** תצוגה מקצה לקצה עם סרגלים שקופים צפים, דפדוף אנכי/אופקי בגלילה או בהחלקה עם אנימציה מסונכרנת להגדרות, הסתרה/החזרה של הסרגלים בלחיצה במרכז המסך, וחלונית טעינה ראשונית אסינכרונית עם כפתור `ביטול` שקוף.
- **מציג ועורך תמונות מתקדם:** תצוגה צפה מלאה עם זום עמוק, ניגון GIF מונפש, פירוק GIF ל-PNG, יצירת GIF מתמונות או מוידאו, תצוגת SVG כולל קוד מקור, הגדרת טפט בחיתוך, ניקוי מטה-נתונים ועריכת תמונה במסך מלא.
- **עורך קוד ומסמכים (20+ שפות):** צביעת תחביר, מספרי שורות מדויקים בגלישה, חיפוש והחלפה פנימיים, Undo/Redo, זום באצבעות, תצוגת Markdown עם מעבר לקוד, גיבוי `.bak` אוטומטי לפני שמירה וצפייה במסמכי Office עם טעינה אסינכרונית ניתנת לביטול.

### נגני וידאו ושמע וחותכי מדיה
- **נגן וידאו (Media3 ExoPlayer):** תמיכה בפורמטים רחבים כולל תיקון יסודי של `TS` / `MTS` / `M2TS` (`SeekableTsExtractor` ו-`TsToMp4Remuxer`), מצב PiP, סרגלים צפים ומחוות מתקדמות הניתנות להפעלה פרטנית (קפיצה בהקשה כפולה, הרצה 2x בהחזקה, גלילה לחיפוש/ווליום/בהירות).
- **בועת שמע, תור ואקולייזר:** בועת נגן תחתונה עם משיכה חלקה לפתיחת הנגן המלא, סידור תור ניגון בגרירה, אקולייזר מובנה, טיימר שינה ובחירת יעד החזרה (לתיקייה הקודמת או לתיקיית השיר).
- **חותכי מדיה והפחתת משקל:** חותך אודיו ווידאו עם פס טווח נוח ומאוחד ומדחס וידאו להפחתת נפח ושינוי רזולוציה.

### ארכיונים, אפליקציות ו-APK
- **מנהל ארכיונים מקיף:** פתיחה, צפייה פנימית בעץ מלא, עריכה חיה, דחיסה וחילוץ של `ZIP`, `TAR`, `TAR.GZ`, `TGZ`, `GZ`, `7Z` ו-`RAR`, כולל פתיחה ויצירה עם סיסמה והגנת `Zip-Slip`.
- **התקנה וגיבוי אפליקציות:** התקנה אוניברסלית של `APK`, `APKX`, `APK+`, `APKS`, `APKM` ו-`XAPK` עם זיהוי גירסה, גיבוי מלא של אפליקציות רגילות (`.apk`) ומפוצלות כולל Split APKs כחבילת `.apks` תקינה ושיתופן.
- **מנתח קוד APK:** פתיחה ישירה של קובצי ה-APK בעץ מסודר (`AndroidManifest.xml`, משאבי XML, `DEX` ו-`ARSC`) בלחיצת כפתור נקייה.

### הגדרות, עדכונים ואבחון
- **מסך הגדרות מאורגן באקורדיונים:** חלוקה לקטגוריות מתרחבות (מראה וערכת נושא כולל רקע וטשטוש, מדיה ומחוות עם שליטה נפרדת בכל מחווה, סידור קטגוריות הבית בגרירה, תצוגה ומיון, אפליקציות ברירת מחדל, אחסון וסל מחזור, עדכונים ואבחון) עם 12 ערכות נושא ו-16 צבעי דגש.
- **עדכונים ודיווח תקלות:** בדיקת עדכונים מ-GitHub כולל תמיכה מאובטחת בתעודות נטפרי המותקנות במכשיר (מוגבלת לדומייני GitHub בלבד), ויומן שגיאות פנימי עם הסרת פרטים מזהים.

## מבנה הפרויקט (Java 17)

```text
app/src/main/java/com/aishhatorah/filemanagerpro/
├── MainActivity.java                 # מסך הבית, אריחי אחסון, OTG ותפריט הוצאה צף
├── FileBrowserActivity.java          # דפדפן קבצים, קטגוריות, סינון וניהול אפליקציות
├── BuiltInViewerActivity.java        # מארח המציגים הפנימיים (ViewerHost)
├── SettingsActivity.java             # מסך הגדרות מתרחב (אקורדיונים) והתאמה אישית
├── UserGuideActivity.java            # מדריך למשתמש המובנה באפליקציה
├── CodeEditorActivity.java           # עורך קוד ו-Markdown
├── AppPackageInstaller.java          # מתקין ופרטי APK/APKS/XAPK
├── ApkSourceInspectorActivity.java   # צפייה בעץ הקבצים של APK
├── StorageUtils.java / PrefsManager.java / ThemeHelper.java / FileIndexDatabase.java
├── viewer/                           # בקרי תצוגה מופרדים לפי סוג תוכן
│   ├── ViewerHost.java               # ממשק הקשר והטעינה של המאגר למציגים
│   ├── ViewerUiHelper.java           # סרגלי מערכת שקופים, רקעים צפים וחלונית טעינה
│   ├── PdfViewerController.java      # מציג PDF מקצה לקצה עם דפדוף ומחוות
│   ├── ImageViewerController.java    # מציג תמונות/GIF/SVG צף
│   ├── VideoViewerController.java    # נגן וידאו Media3 ומחוות
│   ├── AudioViewerController.java    # נגן שמע, אקולייזר ותור ניגון
│   ├── ArchiveViewerController.java  # עץ ופעולות ארכיון פנימי
│   └── OfficeViewerController.java   # תצוגת מסמכי Office
├── browser/                          # מודולי עזר לדפדפן הקבצים
│   ├── AppBackupHelper.java          # טעינת אפליקציות, גיבוי .apk ו-.apks מפוצל ושיתוף
│   ├── FolderSizeHelper.java         # חישוב וזיכרון מטמון אסינכרוני לנפח תיקיות
│   └── MultiSelectSheetHelper.java   # וילון בחירה מרובה הניתן להרחבה בהחלקה
└── settings/
    └── HomeOrderDragAdapter.java     # מתאם סידור בגרירה (Drag & Drop) של אריחי הבית
```

## בנייה והרצת בדיקות

הפרויקט נבנה ב-Java 17 על Android SDK 34 (`minSdk 26`, `targetSdk 34`). בדיקות היחידה (JUnit 4) נמצאות תחת `app/src/test/java/com/aishhatorah/filemanagerpro/`.

```bash
# הרצת בדיקות היחידה
gradle testDebugUnitTest testReleaseUnitTest --no-daemon

# בניית קובץ התקנה חתום (Release)
gradle assembleRelease --no-daemon
```
